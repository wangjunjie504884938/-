# 卫冕战争 - 测试者部署指南

## 一、启动游戏服务器（必需）

### 1. 安装 MySQL
- 下载: https://dev.mysql.com/downloads/installer/
- 安装时记住 root 密码
- 创建空数据库: `CREATE DATABASE weimian;`

### 2. 安装 Redis（可选）
- 下载 Windows 版: https://github.com/tporadowski/redis/releases
- 安装后默认运行在 localhost:6379
- **不装也能用**，服务器会自动降级到直接查 MySQL

### 3. 配置连接信息
打开 `Server/ArpgServer/publish-win/appsettings.json`，修改：

```json
"ConnectionStrings": {
    "Default": "Server=127.0.0.1;Port=3306;Database=weimian;Uid=root;Pwd=你的MySQL密码;Charset=utf8mb4;SslMode=none;"
},
"Redis": {
    "ConnectionString": "127.0.0.1:6379,abortConnect=false",
    "InstanceName": "Arpg:"
}
```

### 4. 启动服务器
双击 `Server/ArpgServer/publish-win/启动服务器.bat`

看到 `Now listening on: http://0.0.0.0:5132` 就说明成功了。

**不需要安装 .NET**，publish-win 文件夹已包含运行时。

---

## 二、打开 Unity 项目

### 1. 用 Unity Tuanjie 引擎打开
- 首次打开会自动重建 Library（可能需要几分钟）
- 等待编译完成，Console 无报错即可

### 2. 选择服务器
- 游戏标题页可以切换服务器
- **本地测试** 选 "本地测试"（http://localhost:5132）
- **远程测试** 选 "卫冕大陆"（http://39.107.141.107:5132）

### 3. 注册账号
- 在登录页注册新账号
- 一个账号最多3个角色槽位

---

## 三、快速测试流程

1. 启动服务器（双击 bat 文件）
2. Unity 点 Play
3. 注册账号 → 选角色 → 进入大本营
4. 点击"进入副本"开始游戏

---

## 四、常见问题

### Q: 启动服务器报数据库连接失败
A: 检查 MySQL 是否启动、密码是否正确、数据库 weimian 是否已创建

### Q: 游戏里显示"无法连接服务器"
A: 确认服务器已启动，游戏里选择了"本地测试"

### Q: 不想装 MySQL 和 Redis
A: 可以直接连远程服务器"卫冕大陆"，不需要本地启动任何东西

### Q: Unity 打开后一堆报错
A: 等待编译完成，如果仍有报错检查 Console 窗口
